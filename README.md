# Mini Post App

A fullstack social media application project inspired by Twitter.

##  Features

### Backend
- JWT Authentication
- Entry-based architecture (POST, COMMENT, REPOST, QUOTE)
- Timeline system
- Layered architecture (Controller - Service - Database)

### Frontend (Planned)
- Modern UI built with React
- Timeline view
- User profile page
- Interactive actions (like, repost, comment)

##  Project Goal

To build a real-world social media application from scratch and gain hands-on experience with backend architecture, database design, and frontend integration.

##  Tech Stack

### Backend
- Node.js
- Express.js
- PostgreSQL
- JWT (Authentication)
- bcrypt (Password hashing)

### Frontend (Planned)
- React
- Tailwind CSS
